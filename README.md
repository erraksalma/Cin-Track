#  Cin-Track

**Cin-Track** est une application web Front-End dédiée à la découverte des films et des séries. Elle permet aux utilisateurs de parcourir un catalogue, rechercher des titres, filtrer les contenus et gérer une liste de favoris.

L'objectif de ce projet est de mettre en pratique les concepts fondamentaux de JavaScript et de développer une interface utilisateur interactive et agréable.

##  Fonctionnalités

-  **Catalogue :** afficher les films et les séries sous forme de cartes.
-  **Recherche dynamique :** rechercher un contenu à partir de son titre.
-  **Filtrage :** afficher tous les contenus, uniquement les films ou uniquement les séries.
-  **Pagination :** organiser les résultats avec 6 contenus par page.
-  **Détails des contenus :** consulter les informations d'un film ou d'une série dans une fenêtre modale.
-  **Gestion des favoris :** ajouter et supprimer des films de sa liste de favoris.
-  **Sauvegarde locale :** conserver les favoris après le rechargement de la page grâce à LocalStorage.
-  **Gestion des erreurs :** afficher un message en cas de problème lors du chargement des données.

##  Concepts JavaScript pratiqués

Ce projet m'a permis de renforcer mes connaissances en JavaScript à travers plusieurs notions :

- Manipulation du DOM.
- Fonctions et tableaux.
- Méthodes `map()`, `filter()`, `find()`, `includes()` et `slice()`.
- Gestion des événements avec `addEventListener()`.
- Délégation des événements avec `event.target.closest()`.
- Programmation asynchrone avec `async/await`.
- Gestion des erreurs avec `try/catch`.
- Stockage des données avec `localStorage`.
- Conversion des données avec `JSON.parse()` et `JSON.stringify()`.
- Organisation du code avec les modules JavaScript.
